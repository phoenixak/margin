Margin

An AI second pass for Harper. It catches what rules can't (agreement, tense, wrong-but-real words, run-ons) and rewrites on request. Not affiliated with Harper or Automattic.

Where your text is checked

Local model

Recommended: gemma4:26b-a4b-it-qat (16 GB GPU). Margin's eval: 100% precision, 92% recall, no correct sentence changed (140 test sentences). Smaller models tend to over-correct.

Gemini API

Stored in this browser's extension storage, which is not encrypted. Anyone with access to this browser profile could read it.

Checking

Sites

Margin checks text fields only on sites you turn on (from its toolbar button). The right-click Margin: rewrite menu works anywhere. Google Docs isn't supported.

    Stored data

    Margin remembers which sentences needed no change (a hash and a date only, no text) and the suggestions you ignored. No telemetry.
