Margin Proofreader for Obsidian: an AI second pass after Harper.

- Uses Harper's own Obsidian plugin for dedup instead of bundling a second copy of Harper, so main.js is about 1 MB (was 28 MB) and syncs with every Obsidian Sync plan. Install and enable Harper's plugin for dedup.
- The wavy underline is drawn in a way every supported Obsidian version renders.
- One-character fixes (a comma) are underlined together with the word before them, so they're visible.
- Built by GitHub Actions from this tag, with signed build provenance for main.js, manifest.json and styles.css.

Desktop only for now. See the README for what's tested.
