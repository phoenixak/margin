# Code of conduct

Margin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good intent, critique ideas and not people, and no harassment of any kind. That applies in issues, pull requests and anywhere the project is discussed.

To report a problem, contact the maintainer through [GitHub](https://github.com/phoenixak) or privately via the Security tab. Reports are kept confidential.
